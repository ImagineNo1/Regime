# رژیم من — نسخه وب

نسخه وب همان فایل اکسل رژیم و کالری‌شماری: ثبت غذا، ورزش و وزن، داشبورد، نمودارها و گزارش هفتگی/ماهانه.
ساخته‌شده با **Next.js 15** و **MongoDB**.

- **چندکاربره:** هر کس می‌تواند حساب بسازد (صفحه ثبت‌نام). داده‌های هر کاربر کاملاً جداست؛ حتی بانک غذا و فعالیت هر نفر مال خودش است. رمزها با scrypt هش می‌شوند.
- **برنامه‌های متعدد:** هر کاربر هر تعداد برنامه (دوره) با بازه زمانی و هدف دلخواه می‌سازد: **کاهش وزن**، **افزایش وزن** یا **حفظ وزن**. ثبت‌های روزانه (غذا، ورزش، وزن) مشترک‌اند و هر برنامه فقط بازه خودش را نشان می‌دهد. برنامه فعال از منوی کناری (یا بالای صفحه در موبایل) عوض می‌شود.

## صفحه‌ها

| صفحه | کار |
|---|---|
| داشبورد | برای برنامه فعال: کالری باقی‌مانده امروز، وزن فعلی، BMI، پیشرفت تا هدف، تاریخ تقریبی رسیدن، کالری لازم برای رسیدن تا پایان دوره، نمودار ۱۴ روز، سهم وعده‌ها |
| برنامه‌ها | ساختن، ویرایش، حذف و فعال کردن برنامه‌ها؛ انتخاب هدف، تاریخ شروع/پایان (یا بدون پایان)، سرعت (کیلو در هفته) و پیش‌نمایش کالری روزانه و زمان رسیدن |
| ثبت روزانه | جستجو و افزودن غذا (با پیش‌نمایش کالری)، ورزش، وزن صبح؛ جابه‌جایی بین روزها با تاریخ شمسی؛ «کپی از دیروز» |
| نمودارها | روزانه (۱۴/۳۰/۹۰ روز یا همه)، روند وزن، هفتگی و ماهانه |
| گزارش‌ها | جدول هفتگی، ماهانه (ماه‌های شمسی) و همه روزها با همان ستون‌های اکسل |
| بانک غذا / فعالیت | افزودن، ویرایش و حذف (برای هر کاربر جدا)؛ هر حساب جدید با ۱۳۳ غذا و ۲۲ فعالیت شروع می‌شود |
| تنظیمات | مشخصات بدن (اسم، جنسیت، سن، قد)، تغییر رمز، خروج |

هدف کالری روزانه: کاهش وزن = مصرف روزانه − کسری (نه کمتر از حداقل ایمن)؛ افزایش وزن = مصرف روزانه + مازاد؛ حفظ وزن = مصرف روزانه (تراز تا ±۲۰۰ «متعادل» حساب می‌شود).

فرمول‌ها همان فرمول‌های اکسل است: BMR با Mifflin-St Jeor، کالری ورزش = (MET − ۱) × وزن × ساعت، و هر ۷۷۰۰ کیلوکالری کسری ≈ یک کیلو.
تغییر کالری یک غذا در بانک، روی ثبت‌های قبلی اثر ندارد.

## راه‌اندازی

### ۱) فایل `.env`

```bash
cp .env.example .env
```
بعد داخل `.env` مقدار `AUTH_SECRET` را عوض کنید (و اگر می‌خواهید، `APP_USERNAME`/`APP_PASSWORD` برای یک حساب اولیه). برای ساختن `AUTH_SECRET`:
```bash
openssl rand -base64 48
```

### ۲) اجرا با Docker (ساده‌ترین)

```bash
docker compose up -d --build
```
سایت روی `http://localhost:3000` بالا می‌آید و MongoDB هم کنارش اجرا می‌شود (داده‌ها در volume به اسم `mongo-data` می‌مانند).

### یا: اجرا بدون Docker

به Node.js 20 یا بالاتر و یک MongoDB (محلی یا MongoDB Atlas) نیاز دارید. آدرسش را در `MONGODB_URI` بگذارید.
```bash
npm install
npm run build
node .next/standalone/server.js     # یا برای توسعه: npm run dev
```
> در حالت standalone باید پوشه‌های static را کنار سرور کپی کنید:
> `cp -r .next/static .next/standalone/.next/ && cp -r public .next/standalone/`

### روی Vercel
مخزن را به Vercel وصل کنید، متغیرهای `.env` را در تنظیمات پروژه بگذارید و برای دیتابیس از MongoDB Atlas (پلن رایگان) استفاده کنید.

## ارتقا از نسخه تک‌کاربره قبلی
اگر نسخه قبلی را اجرا کرده‌اید، کافی است `APP_USERNAME` و `APP_PASSWORD` را در `.env` نگه دارید. بار اول که سایت جدید بالا می‌آید:
- همان حساب ساخته می‌شود و همه ثبت‌های غذا، ورزش، وزن و بانک غذا/فعالیت به آن منتقل می‌شود؛
- تنظیمات قبلی (وزن شروع، هدف، تاریخ شروع، کسری…) به یک برنامه به اسم «برنامه اول» تبدیل می‌شود.

برای بستن ثبت‌نام آزاد (مثلاً بعد از ساختن حساب خانواده): `ALLOW_SIGNUP=false`.

## نکته‌ها
- کوکی ورود ۳۰ روز اعتبار دارد. با تغییر رمز، نشست‌های دستگاه‌های دیگر باطل می‌شود؛ با عوض کردن `AUTH_SECRET` همه نشست‌ها.
- کوکی در حالت production فقط روی HTTPS ارسال می‌شود. اگر سایت را روی شبکه خانگی بدون HTTPS باز می‌کنید، در `.env` بنویسید `INSECURE_COOKIE=1`.
- تاریخ‌ها در دیتابیس میلادی (`YYYY-MM-DD`) ذخیره و در همه صفحه‌ها شمسی نمایش داده می‌شوند. «امروز» به وقت تهران حساب می‌شود.
- حالت تاریک خودکار از تنظیمات سیستم/مرورگر پیروی می‌کند.
- فونت: Vazirmatn (داخل پروژه، بدون نیاز به اینترنت). اگر B Nazanin روی سیستم نصب باشد، به‌عنوان فونت جایگزین استفاده می‌شود.
